# 0.1 Cargo workspace

**Goal:** an empty but complete Cargo workspace that builds, lints and tests clean, so every later task has a place to put code.

**Read:** CLAUDE.md (crate map, coding rules). docs/design.md "Architecture overview".

## Scope

- Root `Cargo.toml` as a virtual workspace, `resolver = "3"`, members `crates/*`.
  - `[workspace.package]`: edition 2024, version 0.0.0, license "MIT OR Apache-2.0", `rust-version` matching the pinned toolchain, publish = false.
  - `[workspace.lints.rust]`: `unsafe_code = "deny"`. `[workspace.lints.clippy]`: `all = { level = "warn", priority = -1 }`.
  - `[workspace.dependencies]`: only what this task uses (internal crates by path, e.g. `jbm-core = { path = "crates/core" }`). Later tasks add more.
  - `[profile.dev.package."*"] opt-level = 2` (dependencies optimized in dev; a voxel engine is unusable at opt-level 0). `[profile.release]`: `lto = "thin"`, `codegen-units = 1`. `[profile.bench]` inherits release.
- `rust-toolchain.toml`: `channel = "1.98.1"`, components `rustfmt`, `clippy`.
- `rustfmt.toml`: `edition = "2024"`, `max_width = 100`, `use_field_init_shorthand = true`.
- Crates (each with `[lints] workspace = true`, fields from `workspace = true`, and a short README.md: purpose, public API so far, invariants, from CLAUDE.md crate map + design doc):
  - `crates/core` → package `jbm-core`, lib, no deps. One public placeholder: `pub const ENGINE_NAME: &str = "just-better-minecraft";` with a doc comment and a unit test.
  - `crates/server` → `jbm-server`, lib, depends on `jbm-core`.
  - `crates/client` → `jbm-client`, lib, depends on `jbm-core`. Must NOT depend on `jbm-server`.
  - `crates/modhost` → `jbm-modhost`, lib, depends on `jbm-core`.
  - `crates/game` → `jbm-game`, binary named `jbm`, depends on client, server, core. `main` prints `ENGINE_NAME` and the package version and exits 0.
  - `crates/testkit` → `jbm-testkit`, lib, depends on `jbm-core`, `jbm-server`. Empty for now (doc comment says: test-only helpers, used as a dev-dependency).
- Each lib has a crate-level `//!` doc comment of 1–3 lines.
- A root `README.md`: one paragraph (what the project is, points to docs/design.md and CLAUDE.md), plus the build/test commands.
- License files: `LICENSE-MIT` and `LICENSE-APACHE` (standard texts, copyright "2026 just-better-minecraft contributors").

## Acceptance

- `cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo fmt --all --check` all pass.
- `cargo run -p jbm-game` prints the engine name and version.
- `cargo tree -p jbm-client` does not contain `jbm-server`.

## Out of scope

No CI files, no wgpu, no tests beyond the placeholder, no changes to docs/ except nothing. Do not edit CLAUDE.md.
