# 0.2 CI on GitHub Actions

**Goal:** every push and PR runs format, lint, tests (including screenshot tests on a software GPU) and a bench smoke-run on macOS and Linux.

**Read:** CLAUDE.md (commands). Note: tasks 0.5 (screenshot tests, env `JBM_REQUIRE_GPU`, `JBM_UPDATE_GOLDEN`) and 0.6 (`cargo bench --workspace -- --test`) are being built in parallel; write CI for those commands even though they may not exist on your branch yet.

## Scope: `.github/workflows/ci.yml` only (plus a short "CI" section in the root README.md)

- Triggers: push to `main`, pull_request, workflow_dispatch. `concurrency` group per ref with cancel-in-progress for PRs.
- Env: `CARGO_TERM_COLOR=always`, `RUST_BACKTRACE=1`, `CARGO_INCREMENTAL=0`.
- Toolchain: install via `dtolnay/rust-toolchain` reading `rust-toolchain.toml` (or rely on rustup auto-install from `rust-toolchain.toml`); cache with `Swatinem/rust-cache@v2`. Pin actions to major versions.
- Job `lint` (ubuntu-latest): `cargo fmt --all --check`, `cargo clippy --workspace --all-targets --locked -- -D warnings`.
- Job `test` (matrix: `ubuntu-latest`, `macos-latest`), `fail-fast: false`:
  - Linux: install Mesa's software Vulkan driver (`sudo apt-get update && sudo apt-get install -y mesa-vulkan-drivers`) and set `JBM_REQUIRE_GPU=1` so screenshot tests must run on lavapipe.
  - macOS: do not set `JBM_REQUIRE_GPU` (hosted macOS runners may have no usable Metal device; tests skip then).
  - `cargo test --workspace --locked`.
  - On failure, upload `target/screenshots/` as an artifact (`actions/upload-artifact@v4`, `if: failure()`, `if-no-files-found: ignore`).
- Job `bench-smoke` (ubuntu-latest): `cargo bench --workspace --locked -- --test`.
- Commit `Cargo.lock` if it is not already committed (it must be, since `jbm-game` is a binary and CI uses `--locked`).

## Acceptance

- The YAML is valid: verify with `python3 -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))"` (install nothing; if PyYAML is missing, say so in the report) and by reading it carefully.
- Every `cargo` command in the workflow passes locally on your branch (screenshot/bench commands that don't exist yet are fine to skip; say which).
- fmt, clippy -D warnings, workspace tests pass.

## Out of scope

No Rust code changes. No release/publish workflows. Do not create the GitHub repo or push.
